一、登记流程
1. 使用设备前，打开本页面登记使用时段
2. 填写部门、姓名、设备、计划起止时间
3. 系统自动检测时段冲突，如有重叠会标红提醒
4. 测试完成后，务必点击"结束使用"填写实际结束时间
二、关机规则（核心！）
谁最后，谁关机。严禁提前关机影响他人。

工作结束前，先查看设备状态看板：
• 若显示"可以关机" → 执行关机
• 若显示"请勿关机"或存在后续登记 → 必须等待所有时段结束后方可关机
• 最后离开人员负责关机，并在记录中确认
三、冲突处理
1. 发现时段冲突时，双方主动协商
2. 优先保障已开机方完成当前测试循环
3. 协商无果时，由测试主管/班组长根据项目紧急度仲裁
四、数据同步说明
本地模式：数据保存在本机浏览器，换设备/清缓存会丢失，多人数据不互通。

云端模式：配置 Supabase 后，所有人数据实时同步，支持多人同时查看和登记。
建议班组长统一配置后，将链接分发给所有人使用。
配置 Supabase 云端同步
本地模式：数据保存在本机浏览器，换设备/清缓存会丢失。

云端模式：配置 Supabase 后，所有人数据实时同步，支持多人同时查看和登记。
配置步骤：
1. 注册 Supabase 并创建项目
2. 进入项目 → Settings → API → 复制 Project URL 和 anon key
3. 在 SQL Editor 执行以下建表语句：
CREATE TABLE equipment_records (
  id BIGINT PRIMARY KEY,
  date TEXT, dept TEXT, user TEXT,
  device TEXT, start TEXT, "end" TEXT,
  actualend TEXT, note TEXT, status TEXT,
  shutdown BOOLEAN DEFAULT false
);
CREATE TABLE equipment_devices (
  id TEXT PRIMARY KEY,
  name TEXT, color TEXT, builtin BOOLEAN
);
